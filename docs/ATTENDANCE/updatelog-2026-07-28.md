# Updatelog 2026-07-28

## 新增

- 新增 P0 考勤模块，支持飞书假勤人脸流水 + 本地工牌刷卡配对生成有效考勤。
- 新增 `attendance_source_records`、`attendance_effective_records`、`attendance_daily_reports`、`attendance_groups`、`attendance_group_members`、`attendance_sync_jobs`。
- 新增后台 `考勤管理` 页面，管理员和只读权限组可查询日报、查看溯源、导出 Excel。
- 新增系统设置项：考勤模块开关、配对间隔、迟到宽限、全量同步时间、免工牌点位前缀、AMT 推送开关和导出字段。
- 新增 `attendance_worker.php` 异步任务入口。

## 变更

- 员工刷卡成功时同步写入本地考勤源表；飞书和 AMT 推送仍由原队列异步处理。
- 飞书事件订阅接入用户打卡成功事件，收到事件后入库源流水并触发单人单日重算。
- 飞书全量同步会先回填同日 `logs` 里的员工刷卡成功记录，再批量查询飞书打卡流水。
- 从飞书读回的 `工牌-` 点位流水标记为 `badge_shadow`，只做溯源，不参与有效考勤配对。
- 每天第一次计划全量同步前会自动同步一次飞书考勤组。
- 操作日志补充考勤管理、同步流水、同步考勤组、导出日报、查看溯源等操作描述。

## 紧急补丁

- 新增“免工牌点位前缀”规则：命中配置前缀的飞书人脸打卡直接算有效考勤，适配没有工牌设备的异地分子公司。
- 免工牌规则按飞书 `location_name` 前缀匹配，支持逗号、分号或换行分隔。

## 注意

- 该模块只计算正式员工考勤；学员、访客仍只保留门禁通行记录。
- 开启模块后建议立即执行一次考勤组同步和当天流水同步。
- `docs/` 默认被 Git 忽略，本次文档需用 `git add -f docs/ATTENDANCE` 提交。
