# Updatelog 2026-07-30

## 变更

- 新增飞书流水 `flow_type` 入库字段，用于按飞书假勤 `type` 配置是否绕过双验证。
- 系统设置新增“直记Type”，支持配置 0-7 类型白名单；命中后飞书流水直接记为有效考勤，不进入补刷提醒，也不发送有效考勤成功提醒。
- 系统设置新增“直记考勤组”，用于完全依赖飞书假勤的考勤组；命中组的任意飞书流水直接记为有效考勤，优先级高于 Type 设置。
- 保留免工牌点位前缀白名单，并纳入统一直记逻辑。
- 双验证补刷提醒新增窗口去重：同一人员、同一上班/下班阶段、同一刷卡/刷脸方式，在配对窗口内连续触发时只提醒一次。
- 直接有效考勤生成后保留日报与溯源，不进入有效考勤机器人提醒队列。

## 注意

- 直记考勤组依赖已同步的飞书考勤组和每日班表；部署后需要先同步考勤组。
- 历史飞书流水如果没有 `flow_type`，会在重算时从 `raw_payload` 中逐步回填。
