# Updatelog 2026-07-29

## 变更

- 考勤日报新增多维状态字段：上班有效、下班有效、迟到、早退、完全缺勤、只刷脸次数、只刷卡次数、因无效考勤迟到/早退。
- 日报列表和状态筛选支持更细分类，便于 HR 查询无效考勤与迟到、早退之间的关系。
- Excel 默认导出改为业务字段，不再输出 `raw_trace` JSON 原文；配置 `trace` 时也只输出溯源摘要。
- 日报按天封存：昨天及以前不再被事件、计划全量、点位修复等自动任务重算。
- 管理员可在考勤管理页点击“重算日报”，手动指定当前筛选日期范围提交重算任务。
- 计划全量同步只处理当天数据，避免自动改写封存日报。
- 刷卡提醒和有效考勤提醒只发送当天记录，跨天未发送的历史提醒会被跳过。
- 只刷脸/只刷卡新增上班、下班边界细分：上班时间及以前单边验证导致迟到、下班时间及以后单边验证导致早退。
- 新增双验证补刷提醒：单边刷脸/刷卡在配对截止前仍未完成双验证时推送红色飞书卡片；只在上班时间及以前、下班时间及以后触发。
- 部署后首次计划任务会提交一次今日日报重算任务，用于修正当天新增关联字段。
- 新增飞书班次详情同步：考勤组时间从班次 `punch_time_rule` 解析，不再全部回落到默认 `09:30-18:30`。
- 新增飞书每日班表缓存：全量同步每批员工先拉取当天 `user_daily_shifts`，日报计算优先按“人员-日期-班次”执行。
- 新增“无需考勤”日报状态：飞书每日班表返回 `group_id=0` 且 `shift_id=0` 时，不再标记迟到、早退或缺勤。
- 兼容跨天班次时间，支持 `24:00` 以后小时数用于夜班类班次计算。
- 明确飞书日历 API 不作为法定节假日来源；节假日、特殊日、排班日以飞书假勤每日班表为准。

## 注意

- 本次迁移只新增字段，不自动重算全部历史日报。
- 如需整理历史数据，请在考勤管理页先设置日期范围，再手动点击“重算日报”。
- 部署后需要在 `config.php` 中补齐 `attendanceShiftGet` 和 `attendanceUserDailyShiftsQuery` endpoint，并在飞书开放平台开通对应读取权限。
